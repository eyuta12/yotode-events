# Yotode Events Website

Professional, bilingual (English/Amharic) event-planning website for Yotode Events, focused on Ethiopian Orthodox and multicultural celebrations.

## Current Site Features

- Single-page experience in `index.html`
- Four-section navigation: Home, Services & Packages, Inspiration, Contact
- English/Amharic language toggle with persistence (`localStorage` key: `yotode-language`)
- Package showcase for Yotode, Qidus, and Melkam with inquiry shortcuts
- Filterable inspiration gallery (weddings, graduations, birthdays, baptisms, shimgelina, more, coffee ceremony)
- Contact form via FormSubmit AJAX endpoint

## Local Preview

Open `index.html` in a browser.

## GitHub Pages

This repository is intended to publish at the default GitHub Pages project URL:

```txt
https://eyuta12.github.io/yotode-events/
```

### Publish Steps

1. Push this repository to the branch used for Pages publishing (typically `main`).
2. In GitHub: **Repository → Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch: `main`, folder: `/ (root)`, then **Save**.
5. Confirm the site loads at `https://eyuta12.github.io/yotode-events/`.
6. Enable **Enforce HTTPS** if GitHub Pages offers it for the default project URL.

### Verification Checklist

- GitHub Pages URL loads (`https://eyuta12.github.io/yotode-events/`)
- HTTPS is enabled when available
- Navigation, language toggle, gallery filters, and inquiry form all work on live site
